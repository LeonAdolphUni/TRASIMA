# Aufgabe 02 – Maven Setup und SimpleV2

_Quelle: Moodle, Kurs Verteilte Systeme (inf-vs-1)_



- Erstellen Sie eine hierarchische Maven-Umgebung.

- Das Root Projekt soll die group.id "dhbw.trasima" haben 

- Erstellen sie ein Unterprojekt mit dem Artifakt für "trasima-aufgabe02"

- Erstellen sie in dem Unterprojekt eine einfache Implementierung für die Simulation von einem/vielen "Virtual Vehicles (V2)"

- Verwenden Sie Threads um mehrere V2 nebenläufig simulieren zu können. 

- Die Anzahl der V2 soll über ein Argument im Main bestimmt werden können. 

- Machen Sie in der ersten Implementierung einen einfachen Ansatz, in dem Sie das V2 für 120 Sekunden fahren lassen.

- Geben Sie für die Aktionen einfache Textausgaben auf StdOut aus!
