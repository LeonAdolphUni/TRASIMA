# Aufgabe 01 – Entwicklungsumgebung installieren

_Quelle: Moodle, Kurs Verteilte Systeme (inf-vs-1)_

Die Entwicklung von TRASIMA wird - wie in der Vorlesung besprochen - grundsätzlich mit JAVA und Maven durchgeführt. 
Weitere Frameworks werden im Laufe der Vorlesung eingeführt.

Zur Minimierung von Seiteneffekten in der Entwicklung MUSS JAVA-21 (21.0.2) und Maven 3.9.12 verwendet werden. 

Installieren Sie auf Ihrem Entwicklungssystem JAVA-21 und Maven (3.9.12)! 

- https://openjdk.org/projects/jdk/21/

- https://maven.apache.org/docs/3.9.12/release-notes.html

Installieren Sie eine Entwicklungsumgebung (Eclipse, VisualCode, ...), die Entwicklungen mit JAVA und Maven unterstützt!
