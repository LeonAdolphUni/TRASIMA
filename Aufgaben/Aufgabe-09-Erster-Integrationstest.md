# Aufgabe 09 – Erster Integrationstest

_Quelle: Moodle, Kurs Verteilte Systeme (inf-vs-1)_



- Builden Sie ein Team aus mindestens 3 Studierenden

- Starten Sie einen gRPC Server auf einem Ihrer Rechner. 

- Starten Sie auf jedem Rechner eine Simulation von V2, die die Daten an den gRPC Server publizieren.

- Starten Sie einen den Jetty Http Server und rufen Sie das Servlet regelmäßig auf und überprüfen Sie dass das System richtig funktioniert.
