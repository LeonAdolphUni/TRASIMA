# Aufgabe 03 – Vorbereitung Dependency Injection

_Quelle: Moodle, Kurs Verteilte Systeme (inf-vs-1)_



- Erstellen Sie eine hierarchische Maven-Umgebung.

- Erstellen sie ein Unterprojekt mit dem Artifakt für "trasima-aufgabe03"

- Im neuen Projekt sollen Sie die Grundlagen für Dependency Injection schaffen, um in folgenden im Projekt mehr Flexibilität zu bekommen.

- Orientieren Sie sich in dieser Implementierung an der Aufgabe 02. 

- Führen Sie eine Schnittstelle (IPositionPublisher) ein, um die Ausgabe der Position auf dem Bildschirm in eine eigene Implementierung der Schnittstelle auszulagern. 

- Ändern Sie die Main-Klassen, so dass Sie die Implementierung von IPositionPublisher ändern können. 

- Erstellen Sie eine zweite Implementierung für die Ausgabe und tauschen Sie diese aus!
