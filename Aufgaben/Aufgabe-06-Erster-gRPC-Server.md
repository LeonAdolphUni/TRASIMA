# Aufgabe 06 – Erster gRPC Server

_Quelle: Moodle, Kurs Verteilte Systeme (inf-vs-1)_



- Integrieren Sie gRPC in ein eigenes Unterproject mit Namen trasima-aufgabe06

- Implementieren Sie eine exemplarische Implementierung eines auf gRPC basierenden Client-Server Systems. 

- indem Sie die Schnittstelle in einer Datei *.proto definieren 

- indem Sie den Server implementieren 

- indem Sie einen einfachen Client implementieren

Ein Beispiel finden Sie unter
