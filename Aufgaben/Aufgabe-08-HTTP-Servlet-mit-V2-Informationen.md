# Aufgabe 08 – HTTP Servlet mit V2 Informationen

_Quelle: Moodle, Kurs Verteilte Systeme (inf-vs-1)_



- Erstellen Sie ein Projekt trasima-aufgabe08 und integrieren Sie die notwendigen Jetty Bibliotheken. 

- Implementieren Sie ein Servlet, dass aus dem bestehenden gRPC Server mit der Funktion FetchAll die Information aller V2 anfragt und diese textuell als Liste auf der Webseite darstellt.

- Implementieren Sie einen einfachen Jetty Server unter dem Pfad /http/trasima das Servlet aufruft.
